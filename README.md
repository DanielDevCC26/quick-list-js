# 📝 Quick List JS

Aplicação web simples para gerenciamento de tarefas, desenvolvida com **HTML**, **CSS** e **JavaScript puro**.  
O projeto permite adicionar e organizar itens de forma rápida, praticando manipulação de DOM e interatividade no front-end.

---

## 🚀 Objetivo do Projeto

Este projeto foi desenvolvido com foco em praticar:

- Manipulação de elementos com **JavaScript**
- Interação com o **DOM**
- Estruturação de páginas com **HTML5**
- Estilização com **CSS3**
- Organização de lógica para aplicações web simples

---

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- Git e GitHub  

---

## 📋 Funcionalidades

- Adicionar novos itens à lista  
- Remover itens da lista  
- Interface simples e intuitiva  
- Atualização dinâmica da página sem recarregar  

---

## 🧠 Conceitos Aplicados

### 🔹 HTML
- Estrutura semântica básica  
- Uso de formulários e inputs  
- Organização de listas com `<ul>` e `<li>`

### 🔹 CSS
- Estilização de layout  
- Organização visual dos elementos  
- Uso de espaçamentos e alinhamentos  

### 🔹 JavaScript
- Seleção de elementos do DOM  
- Manipulação dinâmica de conteúdo  
- Eventos de clique e envio de formulário  
- Criação e remoção de elementos via script  

---

## ▶️ Como Executar o Projeto

Este é um projeto estático, não precisa de servidor.

1. Clone o repositório:
   ```bash
   git clone https://github.com/DanielDevCC26/quick-list-js.git
   ```

2. Abra o arquivo `index.html` no navegador.
